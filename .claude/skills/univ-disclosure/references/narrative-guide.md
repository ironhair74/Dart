# 해석 문단(narrative.md) 형식

`report.py`가 아래 마크다운을 '요약' 카드에 넣는다. 지원 문법: `#`, `##`, `- `, `**굵게**`, 문단.

```markdown
## 한 줄 결론
**(기준연도) 공시 기준, (대학)은 (가장 중요한 발견 1개, 숫자 포함).**

## 강점
- (지표): (값), (비교군 규칙) (n)개교 중 (순위)위. (의미 한 문장)
- …

## 약점·주의
- (지표): (값) → 전년 대비 (yoy)(%p 등). 3년 추세 (label). (의미 한 문장)
- …

## 다음에 볼 것
- (공시만으로 알 수 없는 것, 추가로 확인할 자료 — 예: 학과별 충원 현황, 전형별 경쟁률)
```

## 규칙
- 결론 1문장, 강점·약점 각 2~3개, 다음에 볼 것 1~3개. 전체 250~450자 안팎.
- 숫자는 `analysis.json`에서 그대로(반올림 자리도 같게). `verify.py`가 대조한다.
- 강점·약점 후보는 `strengths`/`weaknesses`(전체 백분위 상·하위 25%)와 `flags`(내부 경보)에서 고른다. 둘 다 비어 있으면 비교군 중앙값과의 차이(`peer.gap_vs_median`)가 큰 지표를 쓴다.
- "내부 경보선"이라는 말을 그대로 쓴다.

## 예시 (가상 데이터)
```markdown
## 한 줄 결론
**2026년 공시 기준, 한빛대학교는 신입생 충원율이 3년 새 99.0%에서 95.8%로 내려 내부 경보선 97%를 밑돌았다.**
```
