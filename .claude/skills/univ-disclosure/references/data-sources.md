# 데이터 받는 법

## 대학알리미 (www.academyinfo.go.kr)

대학알리미는 「교육관련기관의 정보공개에 관한 특례법」에 따라 대학이 공시한 정보를 모아 보여 주는 사이트다(한국대학교육협의회 운영).

1. 대학알리미 접속 → 공시데이터(또는 '대학정보공시 → 공시데이터 다운로드') 메뉴로 들어간다. 메뉴 이름은 개편으로 바뀔 수 있다.
2. 공시연도, 학교종류(대학교), 공시항목(예: 신입생 충원 현황, 졸업생 취업 현황, 중도탈락 학생 현황, 전임교원 확보율, 등록금 현황, 장학금 수혜 현황, 교육비 환원율)을 고른다.
3. 전체 학교를 받는다(비교군 계산에 필요). 엑셀(XLSX) 또는 CSV로 저장한다.
4. 여러 해를 비교하려면 연도별로 받는다. 파일에 '기준년도' 열이 없으면 **파일 이름에 연도(예: `취업률_2026.xlsx`)를 넣는다.** `load.py`가 파일 이름에서 연도를 읽는다.

## 공공데이터포털 (data.go.kr)

'대학알리미 공시정보' 관련 파일 데이터·오픈 API가 올라와 있다. API는 인증키가 필요하고 항목 코드가 달라 이 스킬은 **다운로드 파일을 기본 입력**으로 한다. API로 받은 결과도 CSV로 저장하면 `load.py`가 읽는다(머리글에 '학교명' 열이 있어야 한다).

## 파일 형태의 특징 (load.py 가 처리하는 것)

| 특징 | 처리 |
|---|---|
| CSV 인코딩이 cp949/euc-kr | utf-8-sig → cp949 → euc-kr 순서로 시도 |
| 머리글이 2~3줄(병합 셀: '신입생 충원율' 아래 '모집인원/입학자/충원율') | '학교명' 행부터 하위 머리글을 이어 붙여 `상위 > 하위` 이름을 만든다 |
| 한 지표에 열이 여럿 | '율/률/%'로 끝나는 열을 우선. 동점이면 `ambiguous`로 보고 |
| `-`, `해당없음`, 빈칸, 쉼표 | 결측 처리, 쉼표 제거 |
| 분교·합계 행 | 분교 기본 제외, 합계/평균 행 제거 |
| 전임교원 확보율이 '학생정원 기준'과 '재학생 기준' 둘 | 재학생 기준을 쓴다(`exclude`로 학생정원 기준 제외). 바꾸려면 indicators.csv 수정 |

새 형태의 파일이 안 읽히면 `load_report.json`의 `unmapped_columns`를 보고 `indicators.csv`에 별칭을 더한다.
